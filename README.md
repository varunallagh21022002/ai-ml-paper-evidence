## Reproduction

Open a notebook in GitHub or Colab and use **Runtime → Run all**. The notebooks use public datasets or synthetic data and do not require credentials. Runtime outputs are not automatically treated as verified evidence unless the README explicitly says that saved outputs came from a prior execution.

## Evidence policy

Metrics belong to these runs and must not be attributed to the paper authors. No notebook here claims that all six adaptations are complete, exact reproductions, or equivalent to the cited papers' datasets, methods, or results.
